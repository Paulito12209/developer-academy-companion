# HTML-Modul: Challenges

Wenig Theorie, viel Tippen. Jede Challenge hat:

- **Ziel**: was du danach kannst
- **Aufgabe**: eine Checkliste, die deine Lösung erfüllen muss
- **Starter**: `index.html` im Ordner, die du bearbeitest
- **Hinweise**: in drei Stufen. Öffne Stufe 1 erst, wenn du 5 Minuten feststeckst. Stufe 3 ist fast die Lösung, also nur im Notfall.

Es gibt **keine Musterlösungen** im Repo. Schick deinen Code in den Projekt-Thread, dann bekommst du Feedback und bei Lücken eine Zusatz-Challenge.

## Werkzeuge

- VS Code mit Live Server (Rechtsklick auf `index.html` → *Open with Live Server*)
- Prüfe am Ende jeder Challenge mit dem [W3C Validator](https://validator.w3.org/#validate_by_input): Code reinkopieren, 0 Fehler ist das Ziel.
