# 08 · Boss-Challenge: Deine Online-Visitenkarte

**Ziel:** Du baust eine komplette Seite **ohne Starter-Code** und ohne Hinweise auf Element-Namen. Das ist die Grundlage für dein späteres Portfolio (das wir in CSS stylen).

## Anforderungen

Leere `index.html`, alles selbst:

- [ ] Gültiges Grundgerüst mit sinnvollem Titel und einer `meta description`
- [ ] Seitenkopf mit deinem Namen und einer Navigation zu allen Abschnitten (Anker-Links)
- [ ] Abschnitt **Über mich** mit Foto (alt-Text!), 2 Absätzen und einer Hervorhebung
- [ ] Abschnitt **Skills** als Liste, gruppiert nach HTML / CSS / JavaScript (verschachtelt)
- [ ] Abschnitt **Lernweg** mit mindestens 3 Stationen und maschinenlesbaren Daten
- [ ] Abschnitt **Projekte** mit mindestens 2 Projekten, die jeweils eigenständige Inhalte sind, mit Bild + Bildunterschrift + Link
- [ ] Abschnitt **Kontakt** mit Formular (Name, E-Mail, Nachricht, alle Pflicht, alle mit Label)
- [ ] Fußbereich mit LinkedIn (neuer Tab, sicher) und E-Mail-Link
- [ ] Kein `div`, kein `br` für Abstand, keine übersprungene Überschriften-Ebene
- [ ] W3C Validator: 0 Fehler

## Zusatz-Check (optional, fortgeschritten)

- Öffne Chrome DevTools → **Lighthouse** → Kategorie *Accessibility* → Analyse starten. Ziel: 100.
- Schalte CSS aus (DevTools → Rendering) und lies die Seite von oben nach unten. Ist sie verständlich?

Keine Hinweise diesmal. Wenn du feststeckst, schau in deine Lösungen von 01 bis 07 oder frag im Thread.
